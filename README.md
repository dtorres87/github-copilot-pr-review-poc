# GitHub Copilot PR Review Proof of Concept

This repository is a Proof of Concept to demonstrate AI-assisted Pull Request (PR) reviews using **GitHub Copilot**. It supports an engineering spike for the Map Wizards team.

## Features

- Simple React + TypeScript Vite app with clean code
- Mock user list and search/filtering
- No backend, database, or authentication required
- Demo PRs showcasing AI code review features
- Spike analysis comparing Copilot PR Review with commercial/OSS alternatives

## Quick Start

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start development server:

   ```bash
   npm run dev
   ```

## Why GitHub Copilot?

Copilot PR Review is the preferred solution for AI-powered PR reviews at Map Wizards due to:

- Native GitHub integration
- Enterprise licensing already available
- Lowest incremental cost and maintenance
- High security and privacy standards
